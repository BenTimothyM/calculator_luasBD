# 📐 LineAndShapes-Tools (Kalkulator Luas Bangun Datar)

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge) 

**LineAndShapes-Tools** adalah sebuah skrip berbasis Python yang dirancang untuk menghitung luas berbagai macam bangun datar secara otomatis, cepat, akurat, dan efisien.

> **🌱 Catatan Pembelajaran:** > Repositori ini dibuat sebagai **sarana pembelajaran (learning repository)**. Struktur dan penulisan kode di dalamnya dirancang agar sederhana dan mudah dibaca. Proyek ini sangat terbuka bagi siapa saja yang sedang belajar dasar-dasar pemrograman Python, logika penyelesaian masalah matematika, maupun cara berkontribusi dalam proyek _open-source_.

## 📖 Deskripsi Proyek

Menghitung luas bangun datar (seperti persegi, lingkaran, atau trapesium) secara manual seringkali memakan waktu dan rentan terhadap kesalahan perhitungan (_human error_). Proyek ini hadir untuk menyelesaikan masalah tersebut dengan menyediakan kalkulator geometri instan berbasis _Command Line Interface_ (CLI). 

Sebagai proyek pembelajaran, alat ini sangat cocok digunakan oleh pelajar, mahasiswa, maupun pemula yang membutuhkan referensi kode perhitungan matematis dasar tanpa harus membuka aplikasi kalkulator terpisah atau mencari rumus di internet.

## ✨ Fitur Utama

Saat ini, kalkulator mendukung perhitungan luas untuk 6 jenis bangun datar:
- ⬛ **Persegi**
- ▭ **Persegi Panjang**
- 🔵 **Lingkaran**
- 🔺 **Segitiga**
- ⏢ **Trapesium**
- ▱ **Jajar Genjang**

## 💻 Teknologi yang Digunakan

- **Bahasa Pemrograman:** Python 3.x
- **Library:** _Built-in library_ standar Python (tidak memerlukan instalasi _dependency_ eksternal).

## 🚀 Instalasi

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek ini di mesin lokal Anda:

1. **Clone Repositori**
   Buka terminal/CMD Anda dan jalankan perintah berikut:
```git clone https://github.com/BenTimothyM/LineAndShapes-Tools.git```

2. **Masuk ke Direktori Proyek**
```cd LineAndShapes-Tools```


3. **Persiapan Lingkungan (Environment)**
Pastikan Anda sudah menginstal Python di komputer Anda. Anda dapat mengecek versi Python dengan perintah:
```python --version```


## 💡 Cara Penggunaan


Untuk mulai menggunakan kalkulator, Anda hanya perlu mengeksekusi file utama menggunakan Python melalui terminal:

```python rumus_luas.py```

Setelah *script* berjalan, ikuti instruksi yang muncul di layar terminal. Program akan meminta Anda untuk memilih jenis bangun datar dan memasukkan nilai-nilai yang dibutuhkan (seperti panjang sisi, jari-jari, alas, atau tinggi).

**Contoh Output Terminal:**

```text

--- Kalkulator Luas Bangun Datar ---
1. Persegi
2. Lingkaran
...
Pilih nomor bangun datar: 1
Masukkan panjang sisi: 5
Luas Persegi adalah: 25

```
